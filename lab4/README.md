# Лабораторная работа: Классификация изображений MNIST

Предмет: Искусственный интеллект
Тема: Классификация рукописных цифр (MNIST) полносвязной нейронной сетью на Keras/TensorFlow.

## Структура проекта (порядок запуска)

| Файл | Назначение |
|---|---|
| `common.py` | Общие утилиты: загрузка/предобработка MNIST, построение графиков, фабрики моделей |
| `step1_data.py` | Шаг 1. Загрузка и анализ данных, примеры изображений → `results/mnist_examples.png` |
| `step2_base_model.py` | Шаг 2. Базовая модель (Flatten→256→10), 5 эпох, Adam → `results/history_base.png`, `model_base.keras` |
| `step3_experiments.py` | Шаг 3. Улучшенная модель (512→256→10, 20 эпох, Adam) и та же с RMSprop → графики + `compare_data.npz` |
| `step4_custom_image.py` | Шаг 4. Функция `classify_custom_image()` — демонстрация классификации отдельных изображений с уверенностью |
| `step5_analysis.py` | Шаг 5. Сравнительный анализ: диаграмма точностей и Adam vs RMSprop |

Все графики сохраняются в `results/` (matplotlib в режиме `Agg`, без GUI).

## Архитектуры моделей

**Базовая** (203 530 параметров):
```
Flatten(28x28 → 784) → Dense(256, relu) → Dense(10, softmax)
```
Компиляция: `adam`, `categorical_crossentropy`, `accuracy`.

**Улучшенная** (535 818 параметров):
```
Flatten → Dense(512, relu) → Dense(256, relu) → Dense(10, softmax)
```

Предобработка: нормализация пикселей `/255.0` → [0, 1]; метки → one-hot (`to_categorical`, 10 классов).

## Результаты (тестовая выборка, 10 000 изображений)

| Модель | Оптимизатор | Эпохи | Accuracy | Loss |
|---|---|---|---|---|
| Базовая | Adam | 5 | **97.73 %** | 0.0714 |
| Улучшенная | Adam | 20 | **98.42 %** | 0.0863 |
| Улучшенная | RMSprop | 20 | **98.52 %** | 0.0847 |

**Цель ≥ 95 % — достигнута всеми моделями** (уже базовая модель после 1-й эпохи даёт ~95.2 %).

Демонстрация классификации отдельных изображений (`step4`): 10/10 верных предсказаний, уверенность модели ~100 %.

## Сравнительный анализ (ответы на вопросы работы)

1. **Влияние эпох.** Увеличение с 5 до 20 эпох повысило точность с 97.73 % до 98.42 % (+0.7 п.п.). Прирост есть, но с затухающей отдачей: после ~10 эпох val_accuracy выходит на плато.
2. **Признаки переобучения.** На графиках улучшенной модели виден классический признак: train loss продолжает падать (до ~0.005), а val_loss с ~5-й эпохи перестаёт снижаться и начинает расти (до ~0.086) — разрыв между loss и val_loss увеличивается. Точность на валидации при этом стабилизируется, т.е. лёгкое переобучивание уже есть; борьба — Dropout/L2, ранняя остановка.
3. **Влияние архитектуры.** Добавление слоя и увеличение нейронов (256 → 512+256) дали +0.7 п.п. точности ценой 2.6× параметров — для MNIST прирост скромный, простая сеть уже почти исчерпывает возможности полносвязной архитектуры.
4. **Adam vs RMSprop.** Разница в пределах погрешности (98.42 % vs 98.52 %, RMSprop чуть лучше). Оба оптимизатора сходятся быстро и стабильно; на данной задаче выбор оптимизатора практически не влияет.

## Общий вывод

Реализована полносвязная нейронная сеть для классификации рукописных цифр MNIST.
Проведена полная цепочка: загрузка данных → нормализация и one-hot кодирование →
обучение базовой и улучшенных моделей → визуализация кривых обучения →
классификация отдельных изображений → сравнительный анализ. Все модели превысили
порог 95 %; лучшая точность 98.52 % (RMSprop, 20 эпох). Эксперименты показали
значение мониторинга val_loss для выявления переобучения.
